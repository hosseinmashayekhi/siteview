# بازدید پروژه (SiteView) — نسخه‌ی تست

اپ اندرویدی برای مستندسازی تصویری پروژه‌های ساختمانی:
نقاط عکس‌برداری روی پلان ثبت می‌شوند، در هر بازدید از همان نقاط عکس گرفته می‌شود،
و تایم‌لاین هر نقطه قابل مرور است. عکس‌های ۳۶۰ درجه در نمایشگر کروی نمایش داده می‌شوند.

## اجرا

1. [Android Studio](https://developer.android.com/studio) را نصب کنید (JDK همراه خودش است، نصب جدا لازم نیست).
2. همین پوشه را با **Open** در Android Studio باز کنید و صبر کنید Gradle Sync تمام شود
   (بار اول چند دقیقه طول می‌کشد چون Gradle و SDK دانلود می‌شوند).
3. گوشی را با کابل وصل کنید (حالت Developer Options → USB debugging روشن باشد) و دکمه‌ی Run بزنید.

## طرز استفاده

- یک پلان نمونه داخل اپ هست؛ با دکمه‌ی «تغییر پلان» می‌توانید عکس پلان واقعی خودتان را از گالری انتخاب کنید.
- **لمس طولانی** روی هر جای پلان → ثبت نقطه‌ی عکس‌برداری جدید.
- **تپ روی نقطه** → لیست عکس‌های آن نقطه (تایم‌لاین) + دکمه‌ی عکس جدید:
  - «عکس با دوربین»: دوربین گوشی باز می‌شود.
  - «از گالری (360)»: برای وارد کردن عکس ۳۶۰ که با اپ پانوراماساز یا دوربین ۳۶۰ گرفته‌اید.
    اگر نسبت تصویر ۲:۱ باشد (فرمت استاندارد equirectangular) خودکار به‌عنوان ۳۶۰ شناخته می‌شود.
- تپ روی هر عکس در لیست → نمایش تمام‌صفحه. عکس‌های ۳۶۰ با کشیدن انگشت می‌چرخند و با دو انگشت زوم می‌شوند.
  دکمه‌های «قدیمی‌تر / جدیدتر» بین تاریخ‌های همان نقطه جابجا می‌شوند.

برای تست نمایشگر ۳۶۰ بدون دوربین خاص: عبارت `equirectangular sample image` را جستجو کنید،
یک تصویر با نسبت ۲:۱ دانلود کنید و از گالری وارد اپ کنید.

## ساختار کد

| مسیر | نقش |
|---|---|
| `app/src/main/java/com/siteview/app/data/Store.kt` | مدل داده (نقطه/عکس) و ذخیره‌سازی محلی JSON |
| `app/src/main/java/com/siteview/app/ui/PlanScreen.kt` | صفحه‌ی پلان: زوم، ثبت نقطه، تایم‌لاین نقطه |
| `app/src/main/java/com/siteview/app/ui/ViewerScreen.kt` | نمایش عکس معمولی و ۳۶۰ |
| `app/src/main/assets/viewer.html` | نمایشگر ۳۶۰ (WebGL، کاملاً آفلاین) |

مختصات نقاط به‌صورت نسبی (۰ تا ۱) ذخیره می‌شوند تا به ابعاد تصویر پلان وابسته نباشند —
همین مدل بعداً مستقیم به سرور منتقل می‌شود.

## نقشه‌ی راه

1. **فاز بعد:** بک‌اند (آپلود عکس‌ها) + پنل وب مدیر (Leaflet برای پلان + همین نمایشگر ۳۶۰) + حالت مقایسه‌ی دو تاریخ
2. چند طبقه / چند پروژه
3. راهنمای برگشت به نقطه: چک‌لیست بازدید + overlay عکس قبلی روی دوربین
4. اتصال به SDK دوربین ۳۶۰ (Insta360 / Ricoh Theta)
5. ردیابی خودکار موقعیت با ARCore
